# CatBoost SDSS 0.03 후속 일반화 검증

새 CatBoost는 competition train fold에 SDSS17 100,000행을 weight 0.03으로만 추가하고, validation은 competition 데이터만 유지해 학습했습니다. 단일 모델 OOF balanced accuracy는 기존 RealMLP 피처 CatBoost의 0.9697463777에서 0.9699661012로 0.0002197235 상승했습니다.

단순 확률 혼합은 현재 private 후보 193을 이기지 못했습니다. 그래서 새 모델이 기존 예측과 다른 오류를 고치는지를 확인하기 위해 동일한 22개 소스 스태커와 새 모델을 추가한 23개 소스 스태커를 같은 5시드 x 5폴드로 비교했습니다.

- 새 소스 제외 스태커 OOF: 0.9704390783
- 새 소스 포함 스태커 OOF: 0.9705405776
- OOF 변화: +0.0001014993
- 개선 폴드: 17/25
- 폴드 변화 평균: +0.0000763686
- 폴드 변화 최솟값: -0.0001490240
- 계층별 부트스트랩 개선 확률: 94.4%
- 부트스트랩 95% 구간: [-0.0000217990, +0.0002262916]
- 변경 예측: 1,068행
- 새로 정답 / 새로 오답: 568 / 478
- 정답 순증가: 90행
- 스태커 중요도: 23개 중 2위

부트스트랩 95% 구간이 0을 아주 조금 포함하므로 최종 후보로 바로 승격하지 않았습니다. 대신 독립 신호가 확인된 스태커 연구 소스로 채택했습니다.

그다음 현재 최고 일반화 후보 193을 시작점으로 26개 소스, 1,608개 조합을 탐색하고 상위 120개를 10시드 x 5폴드로 다시 감사했습니다.

새 SDSS 소스 계열은 193을 넘지 못했습니다.

- `stacker_with_catboost_sdss003` 최선 조합: 약 0.970655, 193보다 약 0.000004 낮음
- `our-catboost-sdss003-realmlp` 최선 조합: 약 0.970651, 193보다 약 0.000008 낮음
- 두 소스 모두 감사 상위 120개에 진입하지 못함

전체 탐색에서 raw OOF 최고는 `rollback_weak_gi2_to_69_guarded_research_stack`의 0.9706663178이었습니다. 그러나 다음 이유로 폐기했습니다.

- 193 대비 상승: +0.0000073570
- 최악 meta-fold 변화: -0.0001286088
- 개선 meta-fold 비율: 60%
- 최악 클래스 재현율 변화: -0.0001024389
- 최악 subset 변화: -0.0003116688
- 최종 robust score: -0.0000062440

220~227 후보는 193보다 OOF가 0.0000008830 높은 수준이며 test 예측은 0~1행만 바뀝니다. 실질적인 새 모델이 아니므로 제출 후보로 사용하지 않습니다.

최종 판단:

- SDSS 0.03 CatBoost는 단일 모델 및 스태커 재료로 채택합니다.
- 현재 최종 private 후보는 계속 `193_PRIVATE_CV_oof970659.csv`를 유지합니다.
- 다음 단계는 확장 fold-safe target-stat feature bank입니다.
- count, frequency, entropy, compact interaction 통계를 fold train에서만 계산하고 validation/test에는 transform만 적용합니다.
